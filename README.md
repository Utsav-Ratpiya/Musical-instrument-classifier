# 🎵 Musical Instrument Classifier

A CNN-based Deep Learning project that classifies musical instruments from uploaded images using TensorFlow/Keras.

This project was developed during a Deep Learning workshop competition and deployed publicly using Hugging Face Spaces and Gradio.


## 🚀 Live Demo

🔗 Hugging Face Space: https://huggingface.co/spaces/Utsav-04/musical-instrument-classifier



## 📌 Features

* Multi-class musical instrument classification
* CNN Deep Learning model
* Interactive Gradio web interface
* Real-time prediction system
* Public AI deployment using Hugging Face

## 🎯 Model Information

* Model Type: CNN (Convolutional Neural Network)
* Framework: TensorFlow/Keras
* Input Image Size: 128x128
* Task: Multi-class Image Classification
